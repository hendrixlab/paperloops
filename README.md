#2 The next example will calculate C_eff for all defined loops based on transforms calculated from the provided PDB (-P option) and stems file (-S option). This is also changing the range of tested loop numbers n (from 4 to 6) and total loop length L (from 5 to 8). Also, output files will use the "test" suffix:

./paperloops -n 4 -N 6 -l 5 -L 8  -P data/4ybb_23S.pdb -S data/4ybb_23S.pdb.stems.txt -x test

Warning: for large loop lengths and number of loops, the total number of possible loops is very large! In some cases huge numbers.

#3 To tackle larger loops, consider providing an explicit motif file, and C_eff will only be computed for these provided motifs. 

./paperloops -M large_loops.txt -P data/4ybb_23S.pdb -S data/4ybb_23S.pdb.stems.txt -x large

#4 For a full help menu, run with -h or with no options:

$ ./bin/paperloops -h

Usage: 

./paperloops -P <RNA PDB_file> -S <stems file> -n <N_min> -N <N_max> -l <L_min> -L <L_max> [options]

Options:
	-l <int> : L_min, the minimum total loop length to consider. [default: 0]

	-L <int> : L_max, the maximum total loop length to consider. [default: 4]

	-n <int> : N_min, the minimum number of loops to consider. [default: 2]

	-N <int> : N_max, the maximum number of loops to consider. [default: 5]

	-P <PDB file> : the path to a PDB file to read in. [default: None]

	-S <stems file> : the path to a stems file generated by rna_motif for PDB file. [default: None]

	-i <int> : N_iter, the number of iterations/random trajectories to consider [default 2000].

	-s <int> : N_samples, the number of loop motifs out of all possible to sample [default 0, use all, no sampling].

	-M <motif file> : the path to a motif file to compute C_eff for instead of enumerating all of them.

	-x <output suffix> : a suffix added to the output files. [default: No suffix added]

	-h : print this help menu
